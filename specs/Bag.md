## 1. 개요

배낭 탭은 사용자의 배낭(패킹 리스트) 목록과 생성 진입점이다.
배낭 1개 = 여행/산행 1회의 장비 구성 + 날짜 범위.

## 2. 화면 및 진입

```
app/(tabs)/bag.tsx → BagView
  ├─ BagItemView × n  (배낭 행)
  └─ BagAddView       (생성 모달: 이름 + DateRangeCalendarView 날짜 범위)
```

- 배낭 행 클릭 → `/bag/{id}` ([BagDetail.md](BagDetail.md))
- 생성 완료 → `/bag/{id}`로 자동 이동

## 3. 요구사항

### BAG-1 배낭 목록 `[제안: 패킹 완료율 표시 추가]`

**수용 기준**

- `users/{uid}.bags` 배열의 ID로 `bag` 컬렉션을 조회하고 `startDate desc`로 정렬해 표시한다.
- 각 행에 이름, 날짜, 총 무게(kg), 삭제 버튼을 표시한다. (`editDate`는 저장되지만 목록에 표시되지 않는다 — 미해결 질문 참조.)
- 날짜 표시: 시작일과 종료일이 같으면 `YYYY.MM.DD`, 다르면 `YYYY.MM.DD ~ YYYY.MM.DD`.
- 무게 표시: 저장값(g)을 1000으로 나눠 kg로 표시.
- **패킹 완료율** ([Packing.md](Packing.md)): 패킹 기록이 있는 배낭에만 무게 옆 **칩(pill 뱃지)** 으로 표시한다.
  - 완료(완료율 100%) → `패킹 완료` 칩 (검정 배경 + 흰 글자 — 흑백 톤 유지)
  - 진행 중(챙긴 장비 ≥1, 미완료) → `패킹 {percent}%` 칩 (연회색 배경 + 진회색 글자)
  - 패킹 기록 없음(챙긴 장비 0) → 미표시 (기존 행 그대로)
  - 완료율 = `packedGears ∩ gears` 개수 / `gears` 개수 × 100, 정수 반올림. 교집합 기준이라 배낭에서 뺀 장비의 stale ID는 자연히 제외된다. `gears`가 비면 미표시.
  - 추가 조회 없이 목록 조회로 받은 `bag` 문서 필드만 사용한다 ([DataModel.md](DataModel.md) DM-5).
  - 패킹/상세에서 목록으로 복귀 시 갱신된 값이 보인다 (목록 재로드 경로 기준).

### BAG-2 배낭 생성

**수용 기준**

- `배낭 추가` 버튼 클릭 시:
  - 배낭이 1개 이상이면 **바텀시트**로 `새로 만들기` / `기존 배낭 복사하기` 중 선택하게 한다.
    - `새로 만들기` → 아래 생성 모달.
    - `기존 배낭 복사하기` → 원본 선택 목록(BAG-5).
  - 배낭이 0개면 바텀시트 없이 바로 생성 모달을 띄운다 (기존 동작).
  - 비로그인 처리(로그인 모달)는 기존과 동일하게 바텀시트보다 먼저 적용된다.
- 입력: 이름(필수, 빈 문자열 거부), 시작일(기본: 오늘), 종료일(기본: 내일).
- 캘린더 날짜 선택 규칙: 두 날짜가 모두 선택된 상태에서 새로 누르면 범위를 다시 시작한다. 시작일 이전 날짜를 누르면 시작일을 교체, 이후 날짜는 종료일로 설정한다.
- 시작일/종료일이 없으면 저장하지 않고 알럿을 띄운다.
- 생성 시 `bag` 문서(`weight: 0`, `gears: []`, `shared: false`)를 만들고 `users/{uid}.bags`에 `arrayUnion`, 생성된 `/bag/{id}` 상세로 이동한 뒤 **곧바로 장비 편집 화면**(`/bag/{id}/edit`, [BagDetail.md](BagDetail.md) BD-4)을 연다. 뒤로가기 시 상세가 나온다.

### BAG-3 배낭 삭제

**수용 기준**

- 목록 행의 삭제 버튼 → 확인 다이얼로그(`{이름} 배낭을 삭제할까요?`, 확인 버튼 `삭제`)를 거친다.
- 확인 시 배치로: 담긴 모든 장비의 `bags`/`used`/`useless` 배열에서 해당 배낭 ID 제거 → `bag/{id}` 삭제 → `users/{uid}.bags`에서 제거 ([DataModel.md](DataModel.md) DM-11).

### BAG-4 배낭 복사

사용자는 기존 배낭을 복제해 비슷한 구성의 새 배낭을 빠르게 만들 수 있다.

**수용 기준**

- 목록 행의 삭제 버튼 왼쪽에 복사 버튼을 표시한다. 복사·삭제 버튼 모두 44pt 이상의 히트 영역을 갖는다(`hitSlop`).
- 복사 버튼 → **복사 모달**을 띄운다. 생성 모달(BAG-2)과 동일한 형태(이름 입력 + 날짜 범위 캘린더)에 복사 맥락을 표시한다:
  - 모달 상단에 타이틀 `배낭 복사`를 표시하고, 확인 버튼 문구는 `복사`를 쓴다 (생성 모달은 기존과 동일하게 타이틀 없음/`확인`).
  - 이름: `{원본 이름} 복사본`으로 미리 채운다 (수정 가능, 빈 문자열 거부).
  - 날짜: 생성 기본값과 동일하게 시작일 오늘, 종료일 내일 (캘린더 선택 규칙은 BAG-2와 동일).
  - 복사 확정 처리 중에는 확인 버튼을 비활성화한다 (연타로 인한 중복 생성 방지).
- 확인 시 새 `bag` 문서를 생성한다 ([DataModel.md](DataModel.md) DM-5):
  - `name` / `startDate` / `endDate`: 모달 입력값
  - `gears` / `weight`: 원본 그대로
  - `shared`: `false`, `editDate`: 복사 시점, `userId`: 현재 uid
  - `memo`: 복사하지 않는다 (여행 1회에 종속된 기록이므로)
  - `packedGears` / `packingStartedAt` / `packingCompletedAt`: 복사하지 않는다 — 패킹은 여행 1회에 종속 (`memo`와 동일 원칙, [Packing.md](Packing.md) PK-4)
- 배치로 함께 갱신한다 ([DataModel.md](DataModel.md) DM-11): 새 `bag` 문서 생성 + 담긴 각 장비의 `bags`에 새 배낭 ID 추가 + `users/{uid}.bags`에 추가.
  장비의 `used`/`useless`에는 추가하지 않는다 — **사용 여부 기록은 복사되지 않는다.**
- 복사 완료 후 생성(BAG-2)과 동일하게 `/bag/{새 id}` 상세로 이동한 뒤 **곧바로 장비 편집 화면을 연다**. 완료 토스트(`복사됐습니다`)를 표시한다. 목록 복귀 시 갱신된 목록에 복사본이 표시된다.

### BAG-5 추가 버튼 경유 복사 (원본 선택)

사용자는 배낭 추가 시점에 기존 배낭을 골라 복사할 수 있다.

**수용 기준**

- BAG-2 바텀시트에서 `기존 배낭 복사하기` 선택 → **원본 선택 목록**을 띄운다. 각 행에 배낭 목록(BAG-1)과 동일하게 이름·날짜·무게를 표시한다.
- 원본 행 선택 → 해당 배낭에 대한 복사 모달(BAG-4의 모달·프리필·확정 동작을 그대로 재사용)을 띄운다.
- 이후 확정·데이터·이동·토스트 동작은 BAG-4와 동일하다.

## 6. 엣지 케이스

- **비로그인**: 목록은 빈 배열, 추가 버튼은 로그인 모달 표시. 로그인 변화에 reaction으로 자동 갱신.
- **로딩**: `LoadingView` 표시.
- **빈 목록**: 빈 상태 안내 표시.

## 7. 수동 검증 체크리스트

- [ ] 생성 → 상세 위에 장비 편집 화면이 바로 열림, 뒤로가기 → 상세, 목록 복귀 시 최신(시작일 내림차순) 위치에 표시
- [ ] 복사 확정 → 복사본 상세 위에 장비 편집 화면이 바로 열림 (담긴 장비 체크 상태), 뒤로가기 → 복사본 상세
- [ ] 같은 날짜로 생성 → 단일 날짜 표기
- [ ] 배낭 삭제 → 담겨 있던 장비의 상세 "배낭 기록"에서 해당 배낭이 사라짐
- [ ] 비로그인 → 추가 버튼이 로그인 모달
- [ ] 배낭 복사 → 모달 타이틀 `배낭 복사`·이름 `{원본 이름} 복사본` 프리필·날짜 오늘~내일 → `복사` 버튼 → 복사본 상세 이동 + 토스트
- [ ] 복사본 상세 → 장비 목록·총 무게가 원본과 동일, 메모는 비어 있음
- [ ] 복사 모달에서 이름을 지우고 확인 → 거부(생성과 동일한 알럿)
- [ ] 복사본에 담긴 장비의 상세 "배낭 기록"에 복사본 배낭이 추가로 표시
- [ ] 원본에서 사용 여부를 기록한 장비도 복사본에서는 미기록 상태
- [ ] 복사 직후 원본 삭제 → 복사본과 장비 연결은 유지
- [ ] 비로그인 → 복사 버튼 동작이 로그인 모달(추가 버튼과 동일 규칙)
- [ ] 배낭 ≥1개 → 추가 버튼 → 바텀시트(새로 만들기/기존 배낭 복사하기) 표시
- [ ] 배낭 0개 → 추가 버튼 → 바텀시트 없이 바로 생성 모달
- [ ] 바텀시트 → 기존 배낭 복사하기 → 원본 선택 → 복사 모달 → 복사본 상세 이동 + 토스트
- [ ] 패킹 진행 중 배낭 → 목록 행에 `패킹 {percent}%`, 완료 배낭 → `패킹 완료`, 기록 없는 배낭 → 미표시
- [ ] 패킹 화면에서 몇 개 체크 후 목록 복귀 → 완료율 갱신 확인
- [ ] 패킹된 장비를 배낭 편집에서 제거 → 완료율이 교집합 기준으로 재계산됨
