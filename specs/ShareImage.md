| 항목 | 내용 |

## 1. 개요

배낭 구성을 SNS용 이미지 1장(1080×1350, 4:5)으로 만들어 공유하는 기능.
그리드(고정 슬롯)와 콜라주(AI 배경 제거 + 자동 배치) 두 레이아웃을 제공한다.

## 2. 화면 및 진입

- 배낭 상세의 `내가 가진 장비로 레디샷 만들기`(AI 배지) → `/share-image/{bagId}`.
- 진입 시 `BagDetail`을 초기화해 배낭 데이터를 읽고, **이미지가 있는 장비만** 대상으로 한다.
- 첫 로드 시 의도적으로 2초 로딩(`AI로 이미지 생성 중...`)을 보여준다.

## 3. 요구사항

### SI-1 캔버스 공통

**수용 기준**

- 캔버스: 1080×1350px (4:5), 배경 `#F5F5F5` (`components/bag-detail/share-image/constants.ts`).
- 공통 카드: 무게 카드(총 무게 kg, 8종 그라데이션 색상 토글), 차트 카드(카테고리 도넛 + 상위 5개 범례), 로고 카드(산 배경 + 로고 + `https://useless.my`).
- 로고 카드 배경은 갤러리 사진으로 교체 가능하며, 배경 밝기에 따라 텍스트 색을 조정한다.

### SI-2 그리드 레이아웃

**수용 기준**

- 장비 슬롯 7개 + 무게/차트/로고 카드 고정 배치. 슬롯 0은 2x2 고정.
- 슬롯 1~4는 탭으로 크기 사이클(1x1 → 2x1 → 2x2)을 돌며, 같은 행의 다른 카드 크기가 자동 보정된다. 슬롯 5~6은 `1x2 ↔ 2x2` 토글(가로폭 확장).
- 빈 슬롯은 `탭하여 장비 선택`을 표시하고, 탭하면 장비 선택 모달(이미지 있는 장비 그리드)이 열린다. 롱프레스로 슬롯 비우기.
- 초기 자동 배치: 슬롯 0=텐트, 슬롯 5=배낭, 슬롯 6=침낭, 슬롯 1~4=남은 장비 무게 내림차순.

### SI-3 콜라주 레이아웃

**수용 기준**

- 이미지 있는 모든 장비를 대상으로 greedy packing(상→하, 좌→우)으로 자동 배치한다.
- 카드 크기는 무게 정규화 비율(평균 면적의 0.7~1.5배)로 결정하고, 배치 실패 시 0.8/0.6/0.5배로 축소 재시도, 그래도 실패하면 해당 장비는 건너뛴다(경고 로그).
- 각 장비 이미지는 AI 배경 제거(`@six33/react-native-bg-removal`)를 거치며, 결과는 캐시 디렉토리에 캐시되어 재배치 시 재사용한다. 제거 실패 시 원본 이미지를 사용한다.
- 좌상단 로고 영역(320×110)에는 장비를 배치하지 않는다.
- 배치 후 각 장비는 드래그/핀치 줌 제스처로 수동 조정할 수 있다 (**회전은 미지원** — 코드에서 의도적으로 제거됨).
- 배경 제거 진행 중에는 `AI로 배경 제거 중...` 표시 + 편집 버튼 비활성화.

### SI-4 캡처와 공유

**수용 기준**

- `react-native-view-shot`으로 캔버스를 JPG(품질 0.9)로 캡처한다. 캡처 직전 편집용 UI 요소를 숨긴다.
- iOS: RN `Share.share({ url })`, Android: `expo-sharing.shareAsync(uri)`로 시스템 공유 시트를 연다.
- 갤러리 직접 저장 기능은 없다(공유 시트에 위임).

## 4. 데이터

- 입력: `BagDetail`의 배낭 이름/총 무게/카테고리별 장비(이미지 URL 필수).
- 외부 저장 없음(서버 업로드 없음). 배경 제거 결과만 로컬 캐시.

## 5. 플랫폼 분기

## 6. 엣지 케이스

- **이미지 있는 장비 0개**: 그리드는 빈 슬롯만, 콜라주는 로고/배경만 표시.
- **사진 권한 거부**: `권한 필요` 알럿 후 배경 변경 불가(기능 자체는 유지).
- **배치 공간 부족**: 해당 장비 스킵 + `console.warn`.

## 7. 수동 검증 체크리스트

- [ ] 이미지 없는 장비가 슬롯/콜라주에 나타나지 않는다
- [ ] 그리드 슬롯 크기 사이클과 행 보정 동작
- [ ] 콜라주 배경 제거 후 제스처 편집 가능
- [ ] iOS/Android 각각 공유 시트가 열리고 결과물이 1080×1350 JPG
- [ ] 캡처 결과물에 편집용 UI(버튼 등)가 찍히지 않는다
