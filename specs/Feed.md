## 1. 개요

탐색 탭을 "찾으러 오는 도구"에서 **"구경하러 오는 피드"**로 바꾼다. 인스타그램처럼 장비 카드가 세로로 이어지는 무한 피드를 제공하고, 사용자의 창고 구성(카테고리·브랜드 취향)에 맞춰 관심 있을 만한 장비를 우선 노출한다. 카테고리·브랜드 필터로 피드를 좁힐 수 있다.

- 서버/ML 없이 **클라이언트 개인화**: 관심 신호는 사용자의 창고 보유 장비 분포에서 추출하고, 후보는 Algolia(정렬 replica + facet, [DataModel.md](DataModel.md) DM-10)에서 소싱한다.
- 탐색 홈(Search.md SR-6)을 대체한다 — 피드 출시 시 SR-6은 `[폐기]` 처리. SR-7(목록)·SR-8(브랜드 디렉토리)·SR-9(신제품)의 데이터 계층(browse/BrandRankStore)은 피드가 재사용한다.

## 3. 요구사항

### FD-1 피드 구성과 개인화

**수용 기준**

- 피드는 다음 4개 버킷을 섞어 구성한다(기본 비율 4:2:2:2, 노출 순서는 인터리브):
  1. **관심 카테고리** — 사용자 창고(카탈로그 출신 장비)의 카테고리 분포 상위 2개 카테고리의 인기순(count desc)
  2. **관심 브랜드** — 창고 브랜드 분포 상위 2개 브랜드의 장비 (인기순, companyKorean·company OR facet)
  3. **전체 인기** — count desc
  4. **신제품** — createDate desc
- **제외 규칙**: 내 창고에 이미 있는 장비, `imageUrl`이 유효하지 않은 장비(`'http'` 미포함 — 피드는 비주얼 우선), 중복(같은 id는 1회).
- **콜드스타트**(비로그인 또는 창고 비어 있음): 버킷 3+4만으로 구성(비율 6:4).
- 버킷 소싱은 Algolia 정렬 replica + facet을 사용한다. 각 버킷은 자신의 다음 페이지를 `Promise.all`로 병렬 요청하며(큐가 비었고 페이지가 남은 버킷만), 버킷별 페이지를 독립 진행해 무한 스크롤을 지원한다. 요청 경합은 요청 토큰(`requestId`)으로 방어해 늦게 도착한 이전 요청 결과를 폐기한다.
- **셔플**: 새로고침 시점의 시드로 인터리브 순서를 흔들되, 스크롤 중에는 순서가 바뀌지 않는다(세션 내 안정).
- 개인화 신호(카테고리·브랜드 분포)는 앱 내 데이터만 사용하고 외부로 전송하지 않는다.

### FD-2 피드 카드

**수용 기준**

- 피드는 **2컬럼 그리드**로 표시한다(`FlatList numColumns={2}`, 컬럼 간 균등 간격). 마지막 홀수 카드는 좌측 정렬(빈 칸 우측).
- 카드 구성(위→아래): **정방형 이미지**(셀 폭 꽉) → 브랜드(`Gear.getDisplayCompany()`, 작게) → 이름(`getDisplayName()`, 2줄까지) → 무게(`n g`).
- **창고 담기 CTA**: 이미지 위 우상단 원형 버튼(2컬럼에 맞게 크기 축소하되 터치 타깃 확보). 기존 SR-2/SR-3 규칙 재사용 — 미보유 `+` → 창고 등록 + 배낭 담기 모달, 보유 체크 배지 → 제거 경고. 비로그인 `+` → 로그인 모달.
- `coupangUrl`이 있는 장비는 카드 하단에 **`쿠팡 최저가 ›`**(2컬럼 폭에 맞춘 축약 라벨) 텍스트 링크 노출. 수수료 고지는 카드마다 반복하지 않고 피드 화면 하단/최초 1회 등 공간 효율적으로 처리(GD-5 고지 취지 유지).
- 카드(이미지/텍스트) 탭 → `/gear-detail/{id}`.
- 담기/제거 후에도 피드 스크롤 위치는 유지된다(전체 리로드 금지).

### FD-3 필터 (카테고리·브랜드)

피드 상단에는 필터 UI를 두지 않고(몰입 우선), **하단 중앙 플로팅 `필터` 버튼**으로 통합 필터 시트를 연다.

**수용 기준**

- **플로팅 필터 버튼**: 피드 위 하단 중앙에 고정(탭바 위). 검정 필(pill) 스타일 — 창고 `장비 추가` 버튼과 동일 디자인 언어. 활성 필터가 있으면 라벨에 개수를 표시(`필터 1`, `필터 2`).
- 버튼 탭 → **통합 필터 바텀시트**(정렬 시트와 동일 Animated 패턴). 선택은 시트 안에서 **스테이징**되고 하단 `확인`으로 일괄 적용된다:
  - **카테고리 섹션**: `전체` + 11개 칩 그리드 — 단일 선택, 재탭/`전체`로 해제.
  - **브랜드 섹션**: 브랜드명 검색 입력 + brand-rank 인기순 목록(SR-8 로직 재사용) — **복수 선택**(행 탭 토글, 선택 행은 **체크(✓) 아이콘**으로 강조).
  - **선택 브랜드 요약 칩**: 검색 입력 아래에 선택된 브랜드를 제거(✕) 가능한 칩으로 나열 — 검색 중 목록에서 선택 브랜드가 사라져도 선택 상태를 항상 확인·해제할 수 있다.
  - 헤더 우측 `초기화`: 스테이징 선택 전체 해제(적용은 `확인` 시점).
  - **하단 고정 `확인` 버튼**(검정, 전체 폭 — 배낭 담기 모달의 `닫기` 버튼과 동일 스타일): 스테이징을 적용하고 닫는다. 선택이 있으면 라벨에 개수 표기(`확인 (3)`), 변경 없으면 그냥 닫힘.
  - 브랜드 검색 입력 포커스 시 키보드가 목록·확인 버튼을 덮지 않도록 키보드 회피 처리(배낭 담기 모달과 동일).
  - 오버레이 탭/핸들/뒤로가기 = **취소**(스테이징 폐기, 기존 적용 필터 유지).
- 필터 적용 시 피드 재구성: 해당 필터 인기순 6 : 신제품 4, 개인화 버킷 비활성. 카테고리+브랜드 동시 적용 가능. **복수 브랜드는 OR** — Algolia facetFilters의 같은 내부 배열에 모든 선택 브랜드의 `companyKorean`·`company` 값을 나열해 매칭.
- 플로팅 버튼 개수 = (카테고리 1) + (선택 브랜드 수). 예: 카테고리 1 + 브랜드 2 = `필터 3`.
- 필터 결과 없음: `장비가 없습니다`.
- **인기 순위 진입점**([Search.md](Search.md) SR-4): 하단 우측에 보조 플로팅 버튼 `인기 순위` → 인기 장비 순위 화면(신규 라우트, 기존 SR-4 화면 재사용).

### FD-4 새로고침·페이지네이션

**수용 기준**

- **pull-to-refresh**: 시드 재생성 + 버킷 페이지 초기화 → 새 믹스. 스피너는 RN 기본 RefreshControl.
- **무한 스크롤**: 하단 근접 시 버킷별 다음 페이지 로드·인터리브 이어붙임. 모든 버킷 소진 시 중단(별도 "끝" UI 없음).
- 로딩: 최초 진입 스켈레톤(기존 SearchSkeletonView 패턴), 추가 로드는 하단 스피너.
- 요청 경합: 늦게 도착한 이전 요청 폐기(요청 토큰 — browse와 동일 패턴).

### FD-5 애널리틱스

**수용 기준**

- 카드 탭(`click_feed_card`), 담기(`click_feed_add`), 쿠팡 링크(`click_feed_coupang`), 필터 버튼(`click_feed_filter`), 필터 적용(`click_feed_filter_apply` — 시트 하단 `확인`, 파라미터 `category`·`brand_count`), 필터 초기화(`click_feed_filter_reset`), 인기 순위 진입(`click_feed_ranking`), 새로고침(`click_feed_refresh`)을 [Analytics.md](Analytics.md) AN 규약(스네이크 케이스·40자·식별정보 금지)으로 계측하고 AN-3 표에 등록한다.
- 필터 선택은 시트 안에서 스테이징되고 `확인` 시점에 1회 적용되므로, 카테고리·브랜드 개별 선택 이벤트는 두지 않는다. 적용 결과는 `click_feed_filter_apply`의 `category`·`brand_count` 파라미터로 관찰한다. (구 `click_feed_category`·`click_feed_brand`는 폐기 — 즉시 적용에서 스테이징+확인으로 바뀌며 제거됨.)

## 6. 엣지 케이스

- **비로그인**: 피드 노출(콜드스타트 믹스), 담기만 로그인 모달.
- **Algolia 실패**: 빈 배열 + 재시도 없이 조용히(SR 엣지 정책). 최초 로드 실패 시 빈 상태 문구.
- **이미지 로드 실패**: 카드 유지하되 placeholder(회색) 표시.
- **창고 5개 미만**: 관심 분포가 빈약 — 콜드스타트 믹스로 폴백(임계값: 카탈로그 출신 3개 미만).
