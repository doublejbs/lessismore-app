## 1. 개요

장비별 리뷰 시스템. 최상위 댓글 + 답글(1단계) 구조에 좋아요·@멘션·논리 삭제를 지원한다.
장비 상세의 리뷰 섹션에서 진입한다.

## 2. 화면 및 진입

| 라우트 | 화면 | 역할 |
| --- | --- | --- |
| `/reply/[id]` | ReplyView | 장비의 최상위 댓글 목록 |
| `/reply/[id]/input` | ReplyInputView | 새 최상위 댓글 작성 |
| `/reply/[id]/[commentId]` | ReplyDetailView | 댓글 1개 + 답글 목록 + 답글 입력 |
| `/reply/[id]/[commentId]/edit` | ReplyEditView | 댓글/답글 내용 수정 |

`[id]`는 장비 ID. 목록 → 댓글 클릭 → 상세, 목록 하단 입력 버튼 → 작성 화면.

## 3. 요구사항

### RP-1 댓글 작성

로그인 사용자는 장비에 리뷰 댓글을 남길 수 있다.

**수용 기준**

- 작성 진입 시 닉네임이 없으면 자동 생성한다(`hiker{난수}` — [Auth.md](Auth.md) AU-2).
- 완료 버튼은 공백 제거 후 내용이 있을 때만 활성화된다.
- 저장은 트랜잭션으로 댓글 문서 + 요약 문서(`totalCount`/`parentCount`/`lastCommentAt`)를 함께 갱신한다([DataModel.md](DataModel.md) DM-7).
- 작성 중에는 버튼 비활성 + 로딩 인디케이터를 표시한다.

### RP-2 답글과 깊이 제한

**수용 기준**

- 답글은 최상위 댓글 아래 1단계만 가능하다(답글의 답글 UI 없음). 스토어는 `depth > 2`를 예외로 거부한다.
- 답글 입력에는 대상 사용자 @멘션이 자동 삽입되고, 멘션은 강조색(#9CCC65)으로 렌더된다.
- 답글 입력 `maxLength`는 1000자다. 최상위 댓글 입력에는 길이 제한이 없다(현 동작).

### RP-3 정렬과 페이지네이션

**수용 기준**

- 최상위 댓글: `createdAt desc`(최신순). 스토어는 페이지 로드(`limit` + `startAfter`)를 지원하지만, **현재 UI는 첫 페이지(기본 20개)만 로드하고 추가 로드 트리거가 없다** (미해결 질문 참조).
- 답글: `createdAt asc`(오래된순) 전체 로드.

### RP-4 수정/삭제 권한

**수용 기준**

- 수정·삭제 메뉴는 본인 댓글(`authorId === 내 uid`)에만 노출되고, 스토어에서도 `authorId`를 재검증한다.
- 삭제 시 답글이 있으면 **논리 삭제**(`isDeleted: true`, 내용 `'[삭제된 댓글입니다]'`), 없으면 물리 삭제.
- 삭제 트랜잭션은 요약 카운트와 부모 `replyCount`를 함께 갱신한다.
- `isDeleted` 댓글은 목록 UI에서 필터링되어 보이지 않는다(현 동작 — 미해결 질문 참조).

### RP-5 좋아요

**수용 기준**

- 좋아요는 토글이며 `comment-likes/{userId}_{commentId}` 문서 생성/삭제 + `likeCount` 증감을 트랜잭션으로 처리한다.
- 비로그인 상태에서 좋아요/삭제를 시도하면 전역 로그인 모달(`LogInAlertManager.show()`)을 띄운다.

## 7. 수동 검증 체크리스트

- [ ] 댓글 작성 → 장비 상세 미리보기에 즉시 반영
- [ ] 타인 댓글에 수정/삭제 메뉴 미노출
- [ ] 답글 있는 댓글 삭제 → 답글 보존 여부 확인 (논리 삭제)
- [ ] 좋아요 토글 → 카운트 증감, 재진입 시 상태 유지
- [ ] 답글에 @멘션 강조 표시

## 8. 미해결 질문

- 논리 삭제된 댓글(`[삭제된 댓글입니다]`)이 UI에서 완전히 필터링되면 그 아래 답글 접근 경로가 모호하다 — 의도 확인 필요.
- 최상위 댓글 입력에 길이 제한이 없다(답글만 1000자) — 정책 통일 여부.
- **21번째 이후 댓글은 볼 방법이 없다** — 스토어의 `startAfter` 페이지네이션을 UI(`Reply.ts`, `ReplyView`)가 소비하지 않음. 더보기/무한 스크롤 도입 필요.
- 날짜 포맷 불일치: 답글 상세만 `YYYY. M. D` — 통일 필요.
