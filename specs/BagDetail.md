## 1. 개요

배낭 1개의 상세 화면과 부속 화면들. 카테고리별 장비 목록·무게 차트·메모·사용 여부 기록(앱 정체성인 "쓸모없음" 측정)·
링크 공유·레디샷 진입을 제공한다.

## 2. 화면 및 진입

| 라우트 | 화면 | 역할 |
| --- | --- | --- |
| `/bag/[id]` | BagDetailView | 상세 (무게, 차트, 필터, 장비 목록, 공유, 메모) |
| `/bag/[id]/edit` | BagEditView | 창고 장비 담기/빼기 |
| `/bag/[id]/memo` | BagMemoInputView | 메모 작성/삭제 |
| `/useless/[id]` | BagUselessView | "실제로 사용한 장비" 체크 |
| `/share-image/[id]` | — | 레디샷 ([ShareImage.md](ShareImage.md)) |

## 3. 요구사항

### BD-1 상세 기본 표시

**수용 기준**

- 헤더에 총 무게(kg)를 표시한다. 총 무게는 `bag.weight`(g)/1000.
- 배낭 이름·날짜는 행 클릭 시 모달로 수정할 수 있다. 날짜 수정은 시작일 > 종료일 역순을 거부한다.
- 장비 목록은 카테고리별로 그룹핑해 표시하고, 비어 있지 않은 카테고리만 렌더한다.
- 장비 행 클릭 → `/gear-detail/{gearId}`. 행 메뉴(⋮)에서 수정/삭제 가능.

### BD-2 카테고리 필터와 스크롤 동기화

**수용 기준**

- sticky 필터 바에는 **배낭에 담긴 카테고리만** 노출된다.
- 필터 클릭 시 해당 카테고리 섹션으로 스크롤한다.
- 스크롤 시 현재 보이는 첫 카테고리가 필터에 자동 선택된다.

### BD-3 무게 차트

**수용 기준**

- 접기/펼치기 가능한 스택 바 차트 + 범례(카테고리명, 무게 g, 퍼센트)를 표시한다.
- `배낭/텐트/침낭/매트`는 `베이스(배낭, 텐트, 침낭, 매트)`로 묶어 집계한다.
- 항목은 무게 비중 내림차순으로 정렬하고, 8색 팔레트를 순환 사용한다.

### BD-4 장비 편집 (담기/빼기)

**수용 기준**

- 편집 화면은 창고 전체 장비를 필터/정렬과 함께 보여주고, 배낭에 담긴 장비는 체크 표시한다.
- 장비 토글 시 헤더의 총 무게가 실시간 갱신된다(선택 장비 `weight` 합 / 1000).
- **토글할 때마다 즉시** 트랜잭션 `BagStore.save`가 실행된다(이탈 시 일괄 저장 아님): `bag.gears`/`bag.weight` 갱신 + 추가 장비의 `bags`에 ID 추가 + 제거 장비의 `bags`/`used`/`useless`에서 ID 제거.
- `bag.weight`는 담긴 전체 장비의 `parseInt(weight)` 합으로 다시 계산해 저장한다.
- "장비 추가" 버튼 → `/custom/bag-gear/{bagId}` ([GearEdit.md](GearEdit.md) GE-3).

### BD-5 사용 여부 기록 (useless)

여행 후 실제로 사용한 장비만 체크해 "줄일 수 있는 무게"를 확인하는 핵심 기능.

**수용 기준**

- 진입 문구: 기록 전 `사용 여부 기록하고 줄어든 무게 확인하기`, 기록 후 `사용한 제품만 측정해보니 {usedWeight}kg 까지 줄어들어요`.
- `usedWeight` = 이 배낭에서 `used`에 기록된 장비 무게 합(kg, 소수점 둘째 자리 반올림).
- 기록 화면 초기 상태: `useless` 포함 → 미선택, `used` 포함 → 선택. **배낭 전체에 기록이 하나도 없으면** 전체 선택으로 시작한다. 단, 기록이 일부라도 있는 배낭에서는 미기록 장비가 **미선택**으로 표시된다(미해결 질문 참조).
- 전체 선택/해제를 제공하고, 사용 개수 카운트(`… {n}개 중 {m}개 사용`)를 표시한다.
- 완료 시 각 장비의 `used`/`useless` 배열에 배낭 ID를 반영해 일괄 저장한다(`GearStore.updateGears`).
- 상세의 장비 목록에서 useless 장비는 로고 오버레이 + 50% 투명도로 표시한다.

### BD-6 메모

**수용 기준**

- 멀티라인 입력, 완료 버튼은 trim 후 내용이 있을 때만 활성화.
- 삭제 버튼은 기존 메모가 있을 때만 노출되고, 확인 모달 후 빈 문자열로 저장한다.
- 상세 화면에는 메모가 있으면 내용, 없으면 `메모 작성하기` 링크를 표시한다.

### BD-7 링크 공유

**수용 기준**

- 공유 버튼 → 모달 → 공유 시 `bag.shared = true`로 갱신하고 `https://useless.my/bag-share/{bagId}` 링크를 클립보드에 복사한다.
- 공유 해제 시 `shared = false`.
- 공유 조회(`BagStore.getSharedBag`)는 `shared === true`를 확인하고, 아니면 `공유되지 않은 배낭입니다.` 알럿을 띄운다. 장비는 `bag.userId` 경로의 `users/{userId}/gears`에서 읽는다.

## 6. 엣지 케이스

- **빈 배낭**: 차트 영역에 `장비를 추가해주세요`, 필터 없음.
- **삭제된 장비 참조**: `bag.gears`에 ID가 남아 있어도 실제 조회된 문서만 매핑되어 자동 무시된다.
- **로딩**: 상세 `BagDetailSkeletonView`, 편집/useless는 초기화 전 미렌더.

## 7. 수동 검증 체크리스트

- [ ] 편집에서 장비 추가/제거 → 상세 총 무게·차트·필터 즉시 반영
- [ ] 사용 여부 기록 → "줄어들어요" 문구의 kg 값이 used 장비 합과 일치
- [ ] useless 장비에 오버레이 표시
- [ ] 공유 → 링크 복사, 비로그인 브라우저에서 공유 페이지 열람 가능, 해제 후 접근 불가
- [ ] 이름/날짜 수정 → 목록 화면에 반영

## 8. 미해결 질문

- useless 카운트 문구의 코드 원문이 `전채 {n}개 중 {m}개 사용`으로 **"전채" 오타**다(`components/bag-useless/BagUselessView.tsx`) — 수정 후보.
- 기록이 일부 있는 배낭에서 미기록 장비가 미선택으로 시작하는 동작(BD-5)이 의도인지 확인 필요 — "기록 없음 = 사용으로 간주"가 의도라면 버그.
- `BagEdit.save()`는 호출처가 없는 데드 코드(토글마다 즉시 저장이므로) — 정리 후보.
